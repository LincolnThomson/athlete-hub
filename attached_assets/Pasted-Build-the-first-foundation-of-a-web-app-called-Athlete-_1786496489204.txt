Build the first foundation of a web app called **Athlete Hub**.

Athlete Hub is a mobile-first basketball career and collectible-card platform. The long-term product will let basketball players track their stats, calculate an estimated OVR, earn XP and achievements, earn collectible card packs, open animated packs, and build a digital collection of their career.

For THIS TASK ONLY, build the polished website foundation. Do not build the full product yet.

## TECHNICAL REQUIREMENTS

Use:

* Next.js
* TypeScript
* Tailwind CSS
* A clean component-based architecture
* Responsive design for iPhone, Android, tablet, and desktop
* Motion/Framer Motion for subtle UI animations if appropriate

Do not add payments, AI, pack-opening logic, complex statistics, or social features yet.

## BRAND / DESIGN

Create an original visual identity for Athlete Hub.

The website should feel like:

* A premium basketball video game
* A collectible card game
* A modern sports application

It should NOT look like a generic SaaS dashboard.

Design direction:

* Dark premium background
* Basketball-inspired visual details
* Strong typography
* Large athletic numbers
* Subtle court-line/texture elements
* Cards with depth
* Smooth hover/tap animations
* Premium but not cluttered
* Mobile-first

Use CSS variables/design tokens so the visual system can easily be changed later.

Do not copy the exact branding, logos, assets, or UI of NBA 2K or any other existing product.
